# History of Javascript

### JavaScript was created in May 1995 by Brendan Eich while working at Netscape Communications Corporation. Initially named Mocha, it was quickly renamed to JiveScript, and by December 1995, it became JavaScript — a marketing move to ride on the popularity of Java at the time.
### Its primary goal was to make web pages interactive by allowing scripts to run directly in the browser. The first implementation shipped with Netscape Navigator 2.0, enabling dynamic manipulation of HTML elements without reloading the page.


|                       :Key Early Milestones:                                               |
| ---------------------- | -------------------------------------------------------------------- |
| 1995                   | JavaScript introduced in Netscape Navigator.                         |
| 1996                   | Submitted to ECMA International for standardization.                 |
| 1997                   | ECMAScript 1 released, defining the official language specification. |
| 1998–1999              | ECMAScript 2 and 3 introduced features                               |

|                         :Major Turning Points:                                                            |
| ---------------------- | -------------------------------------------------------------------------------- |
| 2005                   | AJAX popularized, enabling asynchronous data loading (e.g., Gmail, Google Maps). |
| 2006                   | jQuery released, simplifying DOM manipulation.                                   |
| 2008                   | Google’s V8 engine launched, drastically improving JS performance.               |
| 2009                   | Node.js introduced, bringing JavaScript to the server side.                      |
| 2015                   | ECMAScript 6 (ES6) modern features are arrow functions, classes, and modules.    |
