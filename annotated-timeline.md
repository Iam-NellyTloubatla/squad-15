# History of Javascript

- Javascript is a programming language that powers the web in terms of calculations on the browser and it's used also to manipulate the certain actions when you trigger or press a button within the frontend while rendering a complicated task.
- everything that happens on the client side is something that is on a public which is unsecured and at the server side is the more secure and in order to have an access from it there have to be an intermediator called API apart from PHP.

## Characteristics and limitation of Javascript

- With Javascript you can do content manipulation, frameworks such as React, Spelt or Angular Right on the client side.
- Node.js is the typical one on the Backend Server side like Express.js.
- A lot of teams want dynamic flexibility and static safety.
- Types in Javascript belongs to values and never to variables.
- Any information that is to receive from the Client side it has to be 100% because thy might inject some information into the server.
- another limitation that Javascript has is that of type coercion if you code "105"+10 as it might take as strings 10510 and not 115.

## Javascript timeline

1. 1995 - JavaScript created
2. 1997 - ECMAScript standard introduced
3. 2005 - AJAX becomes popular
4. 2008 - Google Chrome + V8
5. 2009 - Node.js
6. 2013 - React
7. 2015 - ES6
8. Today → Modern JavaScript / Full-stack development
